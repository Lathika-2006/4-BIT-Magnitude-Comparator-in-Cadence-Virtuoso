# 4-BIT-Magnitude-Comparator-in-Cadence-Virtuoso
Design and simulation of a 4-bit CMOS magnitude comparator using Cadence Virtuoso in 180 nm technology. The project focuses on transistor-level CMOS gate design, hierarchical schematic development, and functional verification to compare two 4-bit binary numbers and generate greater-than, equal-to, and less-than outputs.
